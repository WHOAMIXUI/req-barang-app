Koneksi Database Google Sheets

Hubungkan file HTML ini ke Google Spreadsheet Anda secara langsung

  1. Buka file Google Sheets Anda.
  2. Klik menu File > Share (Bagikan) > Publish to Web (Publikasikan ke Web).
  3. Pilih opsi Link, ubah "Seluruh Dokumen" menjadi sheet database Anda (contoh: Database_Request Items 2026).
  4. Ubah format output dari "Halaman Web" menjadi Comma-separated values (.csv).
  5. Klik tombol Publish, lalu salin (copy) tautan URL yang diberikan.
  6. Tempelkan (paste) tautan tersebut pada kolom input di bawah ini!

Cara Membuka di Semua Device (Hosting Gratis)

Agar website dashboard ini bisa diakses dari smartphone, tablet, atau laptop manapun secara real-time, Anda bisa menyebarkannya dengan metode gratis:

Opsi A: Netlify Drop (Sangat Mudah!)
  1. Buka website Netlify Drop.
  2. Drag-and-drop file index.html ini ke dalam kotak.
  3. Dalam 5 detik, Anda dapet link website langsung aktif gratis!
Opsi B: Vercel / GitHub Pages

Cocok bagi yang ingin menyinkronkan langsung dengan kode di repository GitHub agar ter-update otomatis jika ada perubahan.
