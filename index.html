Integrasi Realtime Google Spreadsheet

Sinkronkan data secara realtime dari aplikasi ke file spreadsheet Anda

Langkah Setup di Google Sheets Anda:

1

Buat Spreadsheet Baru & Sesuaikan Header

Buat file Google Spreadsheet baru, dan tambahkan nama kolom berikut di baris pertama:

ID Pengajuan Nama Pemohon Cabang Nama Barang Kategori Jumlah Estimasi Harga Urgensi Status Tanggal
2

Buka Script Editor

Pada Google Spreadsheet Anda, klik menu **Extensions (Ekstensi)** -> **Apps Script**.

3

Salin & Tempel Kode Ini

Hapus semua kode bawaan di Apps Script, lalu tempel kode berikut:

4

Deploy sebagai Aplikasi Web (PENTING!)

1. Klik tombol **Deploy (Terapkan)** di kanan atas -> **New Deployment (Penerapan Baru)**.
2. Pilih jenis konfigurasi sebagai **Web App (Aplikasi Web)**.
3. Ubah kolom *"Execute as"* menjadi **Me (Email Anda)**.
4. PENTING: Ubah kolom *"Who has access"* menjadi **Anyone (Siapa saja)**. Jika ini salah, data tidak akan bisa masuk.
5. Klik **Deploy**, klik **Authorize Access**, dan setujui izin akses akun Google Anda.
6. Salin **Web App URL** yang dihasilkan (pastikan link berakhiran /exec, bukan /edit).

5

Sambungkan URL di Menu Pengaturan

Kembali ke tab **Pengaturan & Sync** di aplikasi ini, masukkan URL yang telah disalin, lalu klik Simpan. Aplikasi Anda sekarang terintegrasi secara live ke Google Sheets!

Cara Online-kan ke GitHub Pages

Gratis tanpa biaya hosting sama sekali!

1

Buat Repository Baru di GitHub

Masuk ke akun GitHub Anda, klik **New Repository**. Beri nama bebas (misal: e-request-items) dan pastikan visibilitasnya diatur ke **Public**.

2

Upload File index.html

Klik **Uploading an existing file** pada repository baru Anda, lalu unggah file index.html ini ke sana. Klik **Commit changes**.

3

Aktifkan GitHub Pages

Masuk ke menu **Settings** pada repository tersebut, pilih menu **Pages** di panel samping kiri.

4

Atur Build and Deployment

Pada bagian **Build and deployment**, atur Source menjadi **Deploy from a branch**. Pilih branch **main** (atau master), lalu simpan.

5

Selesai! Aplikasi Anda Online

Tunggu sekitar 1-2 menit. GitHub akan menampilkan link aktif website Anda di bagian atas menu **Pages**.
